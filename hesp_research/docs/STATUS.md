# 项目状态与简历使用边界

当前版本：v0.2。后续工程与真实研究待办见 [CONTINUATION.md](CONTINUATION.md)。下文保留 v0.1 的历史完成范围。研究开始时间采用原始资料中的 2026.04，不能据此推断此前已完成代码或实验。

## 本次完成

- Python 标准库实现的调查状态、证据账本、候选动作与信息增益计算。
- A/B/C 三种可切换控制流程，统一精确去重、预算和日志。
- 执行前预测登记、证据来源追踪、未知响应处理、状态版本失效处理。
- 4 种本地模拟诊断原因、独立模拟验证器、脚本策略。
- 外部模型进程的 JSON 适配接口。
- 自动化单元/集成测试和模拟套件（实际测试结果见 results）。
