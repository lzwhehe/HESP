# 项目状态与简历使用边界

当前版本：**v0.4**（2026-09-23）。结果见 [RESULTS.md](RESULTS.md)，后续计划见 [CONTINUATION.md](CONTINUATION.md)。

## v0.4 已完成

- 两个仅监听回环地址的本地 Web 诊断靶场（web-diag 为开发族，upload-diag 为留出族），带独立验证器、状态漂移和噪声变体。
- 本地开源模型（Qwen2.5 7B / 32B-AWQ / 72B-AWQ）通过 Ollama 或 vLLM 接入；服务端报告 token 用量；模型自行抽取预测表并做校准分析。
- 预先登记的配对主研究：3888 个回合，源码哈希固定，全部通过审计；另有 5880 个回合的选择规则消融。
- 报告了正面结果（弱 Planner 下优势大），也报告了负面结果（32B 上为 0、lookahead 没有跨族泛化、自生成预测表校准差）。

## 简历可以描述的工作范围（v0.4）

“设计并实现一个假设—证据—状态驱动的 LLM Agent 规划框架（预期信息增益选择、执行前预测登记、状态感知的证据账本与结论守卫），自建两个隔离的本地 Web 诊断靶场，并用本地部署的 7B–72B 开源模型完成预先登记的配对对照实验（3888 个回合）：在留出任务族上，对 7B Planner 的验证完成率提升 0.63（95% 区间 0.44–0.79），而这一优势随模型规模增大而缩小（32B 上为 0）。”

使用时请注意：这是自建靶场上的结果，**不能**写成“提高了 Web CTF 完成率”或“完成了真实渗透评估”；数字要与 RESULTS.md 一致，并按本人的实际贡献调整措辞。
