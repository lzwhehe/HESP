# 审计研究预先登记：SOC 场景 LLM 基准中的捷径（v2.0，2026-10-01）

## 起因与问题

第三轮自审后改换选题（`paper/notes/idea_selection.md`）。问题：面向安全运营的 LLM 智能体基准，是否可以不做调查就答对？如果可以，模型的报告成绩有多少可能来自捷径？

已在运行前公开的观察（不进入下面的主要终点，只作为动机）：
- ExCyTIn 训练集 418 题（2026-10-01 证伪实验，`results/audit/excytin_train.json`）：62.9% 的题目只靠词重叠就能把终点告警排第一；78.9% 的答案是终点告警的相邻实体；图捷径命中 30.4%，表捷径命中 24.6%。
- SIABench 告警分诊的 35 条告警（CIC-IDS2017）：规则"告警涉及 172.16.0.1"判对 35/35。该规则是在查看数据之后发现的，属于事后观察；172.16.0.1 是 CIC-IDS2017 文档所述攻击方网络出口地址，属于数据集本身的产物。
- GUIDE 训练集（2026-09-25）：组织内"该检测器以往的判定"查表准确率 0.911；I(grade; org) = 1.03 比特，H(grade) = 1.50 比特。
- OTRF（2026-09-26）：一条基于告警文本的规则区分 46 个告警中的 44 个。

## 冻结的捷径基线（ExCyTIn）

`scripts/audit/excytin_shortcut.py`，规则在训练集上写定，测试集运行前不再修改：
- **graph**：按题目与告警名的词重叠对事件图中的告警排序，取第一名告警；按题目要求的类型（关键词表固定在代码中）筛选它的相邻实体，排除题面已出现的值，取节点编号最小者作为唯一答案。
- **table**：同样的规则，只使用智能体可以查询的 SecurityAlert 表（AlertName 与 Entities 字段）。
- 评分：规范化后的字符串精确匹配（金标准答案等于或包含于预测值）。这比原基准使用的 LLM 评判更严格，原基准的奖励还包含中间步骤的部分得分，所以与报告成绩的比较对捷径不利。

## 假设与终点

- **H1（主要）**：测试集上 graph 捷径的精确匹配准确率 ≥ 0.25。报告点估计和按事件聚类（8 个事件）的 bootstrap 95% 区间（2,000 次，种子 2040）。与原论文表 2 中各模型的平均奖励并列报告（描述性比较）。
- **H2（主要）**：测试集上 ≥ 50% 的题目，终点告警被词重叠排在第一（named）。同样报告聚类区间。
- **H3（探索性）**：8 个事件上，各模型报告的分事件奖励与该事件的 named 比例正相关（对每个模型计算 Spearman 相关系数，报告其分布与符号检验）。若成立，说明模型成绩随捷径可用性而升降。
- **H4（探索性）**：table 捷径在测试集上的准确率与 graph 捷径相差不超过 10 个百分点（说明智能体在环境里确实用得上这一捷径）。

判读：H1 与 H2 都成立，即认定 ExCyTIn 的测试题中有相当比例不需要多跳调查；任何一个不成立，则如实报告，并把论文主张收窄到成立的部分。

## 其他基准（描述性）

- SIABench 告警分诊：报告规则"涉及 172.16.0.1"、多数类（全部判误报）与原论文表 10 中各模型的准确率。该规则为事后发现，明确标注。
- GUIDE、OTRF：沿用 2026-09-25/26 的测量（训练集；GUIDE 测试集不读取）。
- Cyber Defense Benchmark：完整数据需申请，只在公开样例上做探索性检查，不进入结论。
- 我们自己的三个模拟环境：不含 LLM 的控制器解决全部案例的已有结果，作为"由作者构建的环境同样可能被捷径解决"的例子。

## 冻结

- 测试集只运行一次：`python scripts/audit/excytin_shortcut.py --split test --out results/audit/excytin_test.json`，随后运行 `scripts/audit/excytin_analysis.py` 生成区间和相关性。
- 冻结提交见 git 日志（本文件与脚本同一提交）。

## 结果记录（2026-10-01，测试集只运行一次）

- **H2 成立**：named 383/599 = 0.639，事件聚类 95% 区间 [0.517, 0.762]。
- **H1 成立**：graph 精确匹配 216/599 = 0.361，区间 [0.294, 0.435]；高于原论文表 2 中 GPT-4o（0.293）、o3-mini（0.296）、Qwen-3-235b-thinking（0.302）、Gemini 2.5 Flash（0.305）的平均奖励（奖励含部分得分，评判为 LLM）。
- **H4 成立**：table 170/599 = 0.284，区间 [0.210, 0.370]，与 graph 相差 7.7 个百分点。
- **H3（探索性）**：19 个模型中 17 个的分事件奖励与分事件 named 比例正相关，Spearman 中位数 0.21，符号检验单侧 p = 0.0004。相关强度弱，只说明方向一致。
- adjacent 496/599 = 0.828，区间 [0.795, 0.866]。
- 与训练集一致（named 0.629、graph 0.304、table 0.246），没有出现训练—测试差异。
