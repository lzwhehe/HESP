\section{引言}
\label{sec:intro}

告警触发后，分析员必须判断其原因：正在进行的攻击、配置错误、授权活动，还是误报。分析员通过查询认证日志、请求模式、配置、变更工单和威胁情报来缩小候选解释的范围，一旦某条观测支持一种解释、其余解释都被排除，就停止调查。结论决定事件是否升级，而每次查询都要花时间。

人工完成这项工作无法扩展。告警数量超出了分析员的调查能力，而且大多数告警最终证明是良性的~\citep{nodoze}。能够选择查询并读取结果的 LLM 智能体很自然地契合这一循环。然而，许多组织不能或不愿把原始遥测发送给托管模型。对它们而言，现实的选择是足够小、能在单块本地 GPU 上运行的开源权重模型，而近期关于 LLM 驱动攻击调查的工作已经报告，这类模型在复杂案例上落后于闭源模型~\citep{clouseau}。

自动化分诊与调查的工作大致分为两类。第一类构建主机活动的溯源图，并用固定规则或学习模型对其排序或摘要~\citep{nodoze,kairos}。这些系统减少了分析员需要阅读的内容，但并不决定下一步运行哪个查询。第二类使用选择查询并解释结果的 LLM 智能体~\citep{excytin,clouseau}，遵循由模型决定每一步的 ReAct 模式~\citep{react}。这些智能体把调查流程交给模型，而对小型本地模型来说，失败的恰恰是流程。在我们的预注册研究中，自选探针的 Qwen2.5-7B 只有 8\% 到 13\% 的分诊案例以已验证结论结束：它一直探测直到预算耗尽。在我们的提示和服务配置下，Llama-3.1-8B 不会下结论：在 3{,}389 次决策中，它每次都要求再运行一个探针，即使证据已经压倒性、也没有合法探针可用。更大的模型会下结论，但在没有引导时，其引用中有 22\% 到 31\% 无效，并且在给出结论的需处置事件中，分别把 51 个中的 13 个、54 个中的 20 个判为良性。

本文提出 \hesp{}，一个把调查流程放在本地 LLM 智能体之外的控制器。一次调查包含两个决定：\emph{下一步探测什么}和\emph{证据何时足够}，控制器可以接管其中之一或两者。\hesp{} 维护一本关于竞争性解释的账本，依据“每个探针在每种解释下返回什么”的预测表，用贝叶斯规则更新。它按单位成本的期望信息增益对只读探针排序，只接受有当前支持观测的结论，并且可以自行结束调查。模型仍然是规划器：它读取账本，可以提议探针、给出结论或弃权。每条预测都在其观测之前写入日志，每个回合事后都接受审计。

我们把对 \hesp{} 的评测定位为一项受控的机制研究：两个以确定性为主、假设预先给定、探针结果离散的合成任务族，六项预注册研究，两个家族的五个开源权重模型（7B 到 72B），以及 19{,}838 个经过审计的 LLM 回合。用不含 LLM 的开发回合计数得到的预测表，在结束守卫下把 Qwen2.5-7B 的已验证完成率从 0.125 提高到 1.000，与取自生成器的表相当。在规划器信息不变的情况下，信息增益排序在每个会下结论的模型上增加 $+0.26$ 到 $+0.35$。在另一项研究中，控制器侧停止把 Llama-3.1-8B 从 0 提升到 0.917，此后控制器选择对它没有带来可检测的完成率提升，而 Qwen2.5-7B 两部分都需要。这些效应在第二个合成任务族上得到重复，其候选解释来自公开的 Sigma 规则，探针结果由外部模型标注。当控制器采用验证器自身的证据标准时，它在两个任务族上无需任何 LLM 就能完成每一个案例，预先登记的检验也没有发现让 Qwen2.5-72B 决定何时停止能带来任何增益；此前强模型“等待确认”的优势，实际上是更严格停止规则的优势。控制器还改变了安全局面。在我们测试的注入文本下，每个自行决定并给出结论的模型都会服从“关闭该告警”的指令，而带守卫的 \hesp{} 没有把任何攻击判为良性；阻止这一点的组件是结束守卫，仅去掉原始文本虽然也能阻止，却会让最弱模型的大部分案例得不到结论。单条伪造的观测也能骗过控制器，因为它优先依据信息量最大的证据行动。要求良性结论得到两个来源组的佐证，可以把这些案例变为升级，代价是真正的良性告警会增加分析员的工作量。

总结而言，本文的贡献是：
\begin{itemize}
  \item \emph{控制权的分解。}我们表明，小型本地 LLM 在告警分诊上的失败在于流程，且“探测什么”与“何时停止”是两种独立的失败，在规模相近的模型之间表现不同；有了明确的确认规则，不含 LLM 的控制器就能完成我们任务族中的每一个案例（\S\ref{sec:motivation}、\S\ref{sec:rq-stop}、\S\ref{sec:fair}）。
  \item \emph{证据约束及其攻击面。}我们设计并开源了 \hesp{}\footnote{代码、冻结的协议、预测表、结果文件，以及除第一项研究之外所有研究的回合日志（勘误 E-2）见 \repourl。}，由它掌管账本、探针选择、结论接受和停止；我们把其安全行为归因到各个组件：守卫阻止注入式结案，伪造来源击败提前停止，按来源组佐证以可测的代价恢复安全性（\S\ref{sec:approach}、\S\ref{sec:adversarial}）。
  \item \emph{受控且可复现的评测。}六项预注册研究，包括冻结的协议与源码哈希、盲对照、相同证据标准下的不含 LLM 参照、更宽的预测表误差测试、第二任务族、对三个公开数据集为何不适配本评测的审查，以及我们自身错误的记录（\S\ref{sec:setup}、\S\ref{sec:results}、附录~\ref{app:errata}）。
\end{itemize}
