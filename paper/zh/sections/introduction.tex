\section{引言}
\label{sec:intro}

告警触发后，分析员必须判断其原因：正在进行的攻击、配置错误、授权活动，还是误报。分析员通过查询认证日志、请求模式、配置、变更工单和威胁情报来缩小候选解释的范围，一旦某条观测支持一种解释、其余解释都被排除，就停止调查。结论决定事件是否升级，而每次查询都要花时间。

人工完成这项工作无法扩展。告警数量超出了分析员的调查能力，而且大多数告警最终证明是良性的~\citep{nodoze}。能够选择查询并读取结果的 LLM 智能体很自然地契合这一循环。然而，许多组织不能或不愿把原始遥测发送给托管模型。对它们而言，现实的选择是足够小、能在单块本地 GPU 上运行的开源权重模型，而近期关于 LLM 驱动攻击调查的工作已经报告，这类模型在复杂案例上落后于专有模型~\citep{clouseau}。有两个事实让这成为一个安全问题，而不只是能力问题。第一，智能体读到的证据有一部分是攻击者写的：请求载荷、用户代理、进程命令行和工单文本都会进入日志，而通过检索内容实施的间接提示注入已有充分记录~\citep{greshake2023,agentdojo}。第二，攻击者在分诊中的目标具体而廉价：不是接管智能体，而是让告警被结为良性，或者悬而不决。

现有方法把整个流程交给模型。基于溯源的系统对主机活动排序或摘要~\citep{nodoze,kairos}，但不决定下一步运行哪个查询；LLM 调查智能体~\citep{excytin,clouseau}遵循 ReAct 模式~\citep{react}，由模型选择每个探针、读取每个结果并决定何时停止。对小型本地模型而言，失败的恰恰是流程。在我们的研究中，自行选择探针的 Qwen2.5-7B 只有 8\% 到 13\% 的分诊案例以已验证的结论结束；在我们的提示与服务配置下，Llama-3.1-8B 在 3{,}389 次决策中从未给出结论；更大的模型会给出结论，但其引用中有 22\% 到 31\% 是无效证据。而当我们把“关闭告警”的指令写进日志字段时，每个自行决定并给出结论的模型都服从了它。

本文研究\emph{攻击者从哪里进来}，把它看作允许模型做哪些决定的函数。一次调查包含三项活动：选择探测什么、读取每个结果、判断证据何时足够。我们构建了 \hesp{}：一个控制器，它维护候选原因的账本，依据计数得到的探针—结果表用贝叶斯规则更新；按单位成本的期望信息增益对只读探针排序；只接受有当前支持性观测的结论；并且可以自行结束调查。模型仍然是规划器，可以提议探针、结束或弃权；在日志是原始文本时，它还是把日志读成账本词表的读取器。成本感知的测试选择与假设识别是经典方法~\citep{dekleer1987,golovin2010}，\hesp{} 原样使用教科书准则。新的东西是这样一个准则与本地 LLM 之间每种控制权分配的实测攻击面，以及关闭每条通道的规则和它的代价。

我们把评测定位为一项受控的机制研究：三个候选原因预先给定的合成任务族；八项采用内部冻结前瞻性协议的研究；五个开源权重模型（7B 到 72B）；以及 23{,}582 个经过审计的 LLM 回合。三条通道构成结果的主线，各对应一种分配。\emph{模型决定时}，注入的指令在每个模型上都成功；只接受账本支持的结论的结束守卫在每个模型上都挡住了它，注入的效果降为未决案例的代价。\emph{控制器决定时}，攻击者必须伪造证据而不是文本，而一个伪造的来源就够了，因为控制器先按信息量最大的观测行动；要求良性结论得到两个不同来源组的佐证会把这些案例变成升级，代价落在诚实的良性案例上，取决于它们有几条特征。\emph{模型读取时}——格式变化让规则解析器失效后它必须读取——攻击者一次写进所有来源：在每条日志的自由文本字段里写入一致的良性故事，在采纳全部声称的脚本读取器下击穿来源组佐证，并在 Qwen2.5-7B 上把攻击结为授权扫描（\S\ref{sec:rawlog}）。一条读取器信任规则（模型解析出的观测可以确认攻击，但永远不能确认良性结论）关闭了这条通道；只要规则解析器读不出来，其代价就由诚实的良性案例承担。最后，这种分配是可以承受的：“探测什么”与“何时停止”是小模型两种独立的失败，而采用验证器的证据标准后，控制器无需任何 LLM 就能完成 sec-triage 与 sigma-triage 的每一个案例。预先登记的比较没有发现让 Qwen2.5-72B 决定何时停止带来增益，给基线同样清楚的提示后它们仍然远远落后。这个标准本身是一种取舍：联合证据能解决更多“原因使用相同工具”的案例，但会把一部分攻击结为与之相似的合法活动。

本文的贡献如下：
\begin{itemize}
  \item \emph{控制权分配的攻击面。}我们把本地 LLM 分诊智能体的安全行为归因到每个决定的持有者：模型决定时注入指令成功，结束守卫挡住它；决定的控制器被伪造来源击败，来源组佐证恢复安全；读取的模型通过所有来源同时重新打开通道，读取器信任规则关闭它（\S\ref{sec:injection}--\S\ref{sec:rawlog}）。
  \item \emph{分配的代价。}我们用盲对照说明探针选择与停止是两种独立的失败，在规模相近的模型之间也不同；带明确确认规则的控制器无需 LLM 就能完成两个确定性任务族的每一个案例，我们测试的模型没有一个能在其上增加什么，即便提示是为帮助基线而选出的；接受联合证据则以错误结论换取自动化（\S\ref{sec:cost}、\S\ref{sec:policy}）。
  \item \emph{受控且可复现的评测。}\hesp{}\footnote{代码、冻结协议、预测表、结果文件，以及除第一项研究外（勘误 E-2）每项研究的回合日志见 \repourl。}、带源码哈希的内部冻结协议、相同证据标准下的不含 LLM 参照、每种读取器攻击的脚本上界、表误差测试、另外两个任务族、对三个公开数据集的审计，以及我们自己错误的记录（\S\ref{sec:setup}、附录~\ref{app:errata}）。
\end{itemize}
