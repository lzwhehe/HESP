\section{引言}
\label{sec:intro}

告警触发后，分析员必须判断其原因：正在进行的攻击、配置错误、授权活动，还是误报。分析员通过查询认证日志、请求模式、配置、变更工单和威胁情报来缩小候选解释的范围，一旦某条观测支持一种解释、其余解释都被排除，就停止调查。结论决定事件是否升级，而每次查询都要花时间。

人工完成这项工作无法扩展。告警数量超出了分析员的调查能力，而且大多数告警最终证明是良性的~\citep{nodoze}。能够选择查询并读取结果的 LLM 智能体很自然地契合这一循环。然而，许多组织不能或不愿把原始遥测发送给托管模型。对它们而言，现实的选择是足够小、能在单块本地 GPU 上运行的开源权重模型，而近期关于 LLM 驱动攻击调查的工作已经报告，这类模型在复杂案例上落后于闭源模型~\citep{clouseau}。

自动化分诊与调查的工作大致分为两类。第一类构建主机活动的溯源图，并用固定规则或学习模型对其排序或摘要~\citep{nodoze,kairos}。这些系统减少了分析员需要阅读的内容，但并不决定下一步运行哪个查询。第二类使用选择查询并解释结果的 LLM 智能体~\citep{excytin,clouseau}，遵循由模型决定每一步的 ReAct 模式~\citep{react}。这些智能体把调查流程交给模型，而对小型本地模型来说，失败的恰恰是流程。在我们的研究中，自选探针的 Qwen2.5-7B 只有 8\% 到 13\% 的分诊案例以已验证结论结束：它一直探测直到预算耗尽。在我们的提示和服务配置下，Llama-3.1-8B 不会下结论：在 3{,}389 次决策中，它每次都要求再运行一个探针，即使证据已经压倒性、也没有合法探针可用。更大的模型会下结论，但在没有引导时，其引用中有 22\% 到 31\% 无效，并且在给出结论的需处置事件中，分别把 51 个中的 13 个、54 个中的 20 个判为良性。

本文研究应当从模型手里拿走哪些决定，以及由此形成怎样的安全边界。一次调查包含两个决定：\emph{下一步探测什么}和\emph{证据何时足够}，控制器可以接管其中之一或两者。我们构建了 \hesp{}：一个控制器，它维护候选原因的账本，依据计数得到的探针—结果表用贝叶斯规则更新；按单位成本的期望信息增益对只读探针排序；只接受有当前支持观测的结论；并且可以自行结束调查；模型仍是规划器，可以提议探针、给出结论或弃权。考虑成本的测试选择和假设识别是经典问题~\citep{dekleer1987,golovin2010}，\hesp{} 原样使用教科书准则。新的是：实际测量了这样一个准则与 LLM 之间的控制权分配，以及每种分配的安全后果。

我们把评测定位为一项受控的机制研究：三个候选原因预先给定的合成任务族，其中两个几乎是确定性的，一个的结果是概率性且相互重叠的；七项采用内部冻结前瞻性协议的研究；五个开源权重模型（7B 到 72B）；以及 21{,}278 个经过审计的 LLM 回合。三个结果构成本文的主线。第一，“探测什么”与“何时停止”是两种独立的失败：在规划器信息不变的情况下，信息增益排序在每个会下结论的模型上增加 $+0.26$ 到 $+0.35$，而挽救 Llama-3.1-8B 的是控制器侧停止（从 0 到 0.917），Qwen2.5-7B 则两者都需要。第二，一旦控制器采用验证器的证据标准，它在 sec-triage 和 sigma-triage 上无需任何 LLM 就能完成每一个案例，预先登记的比较也没有发现让 Qwen2.5-72B 决定何时停止带来任何增益；此前强模型“等待确认”的优势，实际上是更严格的证据规则的优势。这条规则是一条前沿上的一个点：接受联合证据能解决更多“原因使用相同工具”的案例，但会把一部分攻击结为与之相似的合法活动，并且在真实原因不在候选集合中时给出错误原因。即使给基线同样清楚的提示，它们仍然远远落后。模型剩下的唯一作用是读取原始日志：在这里，小模型能读懂让规则解析器完全失效的新格式，但也可能被说服采纳攻击者的读数。第三，安全边界很清晰。在我们测试的四种注入文本下，每个自行决定并给出结论的模型都会服从“关闭该告警”的指令，而结束守卫在每个模型上都挡住了它；单一伪造来源能击败控制器，因为它优先依据信息量最大的证据行动；要求良性结论得到两个来源组的佐证，可以把这些案例变为升级，给真正良性案例带来的代价取决于它们有多少独有特征。

总结而言，本文的贡献是：
\begin{itemize}
  \item \emph{控制权的分解。}我们用盲对照表明，探针选择与停止是小型本地 LLM 的两种独立失败，在规模相近的模型之间表现不同；有了明确的确认规则，不含 LLM 的控制器就能完成两个确定性任务族中的每一个案例，我们测试的模型都无法在此之上增加什么；改为接受联合证据，则是以错误结论换取自动化（\S\ref{sec:rq-stop}、\S\ref{sec:fair}）。
  \item \emph{每种分配的安全边界。}我们把安全行为归因到各个组件：结束守卫阻止注入式结案，伪造来源击败提前停止，确认规则把缺失的原因变为升级而不是错误结论，按来源组佐证以可测的代价恢复安全（\S\ref{sec:adversarial}、\S\ref{sec:mismatch}）。
  \item \emph{受控且可复现的评测。}\hesp{}\footnote{代码、冻结的协议、预测表、结果文件，以及除第一项研究之外所有研究的回合日志（勘误 E-2）见 \repourl。}、带源码哈希的内部冻结协议、相同证据标准下的不含 LLM 参照、预测表误差测试、另外两个任务族、原始日志解析、对三个公开数据集的审查，以及我们自身错误的记录（\S\ref{sec:setup}、附录~\ref{app:errata}）。
\end{itemize}
