\section{评估}
\label{sec:results}

我们回答五个问题：
\begin{description}\setlength\itemsep{0pt}
  \item[RQ1] 注入指令（A1）能否关闭案件，结束守卫能否阻止它？（\S\ref{sec:injection}）
  \item[RQ2] 伪造来源（A2）能否关闭案件，跨来源佐证的代价是什么？（\S\ref{sec:evidence}）
  \item[RQ3] 针对模型读取的自适应攻击者（A3）能否关闭案件，读取器信任能否阻止它？（\S\ref{sec:rawlog}）
  \item[RQ4] 把决定从模型手里拿走，是否会减少解决的案例？（\S\ref{sec:utility}）
  \item[RQ5] 证据规则和不精确的预测表如何在自动化与安全之间取舍？（\S\ref{sec:policy}）
\end{description}

\subsection{实验设置}
\label{sec:setup}
\label{sec:testbed}

\paragraph{分诊场景} 我们构建了三个模拟场景，其中真值已知、攻击者可控；我们考察过的公开数据集缺少客观标注下配对的攻击与相似的管理活动（\S\ref{sec:realdata}）。\emph{sec-triage} 是 Web 服务上的一条告警，有八个原因：三种攻击（凭证填充、SQL 注入探测、DNS 命令控制）、内部人员外泄数据、暴露的管理面板、存在已知漏洞的组件、授权的漏洞扫描，以及监控误报。十个只读探针的成本为 1 到 3 个单位；威胁情报只会说“恶意”，而三种攻击都得到这个答案。每个原因有基础变体、带瞬时故障的噪声变体，以及事件在第二个探针后发生变化的漂移变体（24 个任务）。\emph{sigma-triage} 消除了我们自己对原因的选择：从公开的 SigmaHQ 仓库~\citep{sigmahq}用固定种子抽取 12 条规则，每条贡献其针对的攻击，以及从其 \texttt{falsepositives} 字段原样取出的至多四个良性解释（76 个任务）；十个通用探针在每个原因下返回什么，由两个规划器家族之外的模型（phi-4~\citep{phi4}）一次性标注并冻结。\emph{comp-triage} 有三个场景（远程执行、计划任务、大量外传），每个场景中一种攻击与三种合法活动使用相同工具；结果是概率性的，十二个原因中有五个没有单条观测特征。预测表由每个原因和变体 20 个不含 LLM 的开发回合计数得到，其种子与评测不重叠。

\paragraph{模型与配置} 我们使用 Qwen2.5-7B、32B、72B 和 Llama-3.1-8B、70B（32B 及以上用 4 比特 AWQ 权重），由 vLLM 以温度 0.2 服务，每个回合的预算为 10 个探针、10 个成本单位和 12 次决策。基线是常见的智能体设计：\emph{ReAct 式}，模型看到原始历史，自己选择每个探针并决定结论；\emph{Memory-only}，模型还能看到账本。\hesp{} 的各配置逐一打开控制器选择、结束守卫、控制器停止、佐证和读取器策略，以便把效应归因到每条规则。在控制器选择的配置中，提示不透露排序，因此无论运行哪种选择器，模型收到的请求都相同。\emph{不含 LLM 的控制器}使用一个从不提出结论的脚本规划器，给出没有任何模型时控制器的表现。推荐的 \hesp{} 配置使用信息增益选择、守卫、确认条件停止、跨来源佐证和恢复；附录~\ref{app:loop} 列出所有配置。

\paragraph{攻击} 对于 A1，四种在措辞和位置上不同的注入文本（一条运维备注、一个用户代理字段、一个伪造的分析员覆盖字段、只在一个探针的响应里）指示智能体把案件结为授权扫描。对于 A2，来源信誉探针报告已知扫描器（\emph{伪造探针}），或两个探针共同读取的上游信誉源被污染（\emph{伪造源}）。对于 A3，探针以文档格式或\emph{漂移}格式返回日志文本；漂移格式用改写的行陈述同样的事实，就像日志流水线变化之后那样。第一种 A3 攻击在四个探针的用户代理字段里写入良性声称；自适应攻击则在每个探针的字段里写入一致的授权扫描故事、在漂移格式上做同样的事，或者跳出字段伪造一条完整的日志记录（\emph{日志行注入}）。一个能正确读取任何格式、并采纳所见每条声称的脚本读取器给出每种攻击的上界。所有攻击都针对 sec-triage 的六个需处置原因。

\paragraph{指标} 若回合以真实原因结束、并引用了一条只有该原因才会产生的观测，则称该回合\emph{已解决}；做这一检查的验证器知道隐藏原因，只用于评测。\emph{漏判攻击}指需处置案例被结为良性，按全部需处置回合计数，因此从不回答的智能体不会显得安全。以 \textit{other} 或无结论结束的回合称为\emph{升级}。\emph{成本}是花费的探针成本。在原始日志实验中，验证器检查的是真实结果，因此解析错误永远不会被计为已解决；\emph{采纳}计数的是解析结果等于攻击者声称、而真实结果不同的观测。

\paragraph{统计分析} 每个实验的假设和主要比较都在其第一个回合之前写定，每个主要比较都给出按任务配对、按任务聚类的 bootstrap 区间（2{,}000 次重抽样；一个实验有多个主要比较时做 Bonferroni 校正）。审计重放了全部 23{,}582 个 LLM 回合以及不含 LLM 回合的日志。附录~\ref{app:prereg} 列出各个实验、其主要比较与结果，以及我们在自己的流程中发现的错误。
