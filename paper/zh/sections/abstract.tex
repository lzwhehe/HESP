\begin{abstract}
安全运营中心收到的告警远超分析员的调查能力，而无法把遥测发送给托管模型的组织，只能在自有硬件上用小型开源权重 LLM 实现分诊自动化。现有的 LLM 智能体把调查流程交给模型，而小型本地模型恰恰在流程上失败：探测却不收敛、不给出结论，或者服从攻击者写进日志的指令。我们提出 \hesp{}，一个把调查流程放在模型之外的控制器：它维护一本关于竞争性解释的账本，按单位成本的期望信息增益选择只读探针，只接受有当前证据支持的结论，可以自行结束调查，并在每条观测之前把预测写入日志。我们把评测定位为一项受控的机制研究：在两个以确定性为主、假设预先给定、探针结果离散的合成任务族上，进行六项预注册研究，使用五个开源权重模型（7B 到 72B），共 19{,}838 个经过审计的 LLM 回合。由开发回合估计的预测表与来自生成器的表效果相当，无需直接访问生成器概率。“探测什么”与“何时停止”是两种独立的失败：在结束守卫下，控制器选择把 Qwen2.5-7B 的已验证完成率从 0.125 提高到 1.000；在另一项研究中，控制器侧停止把在我们的提示下不下结论的 Llama-3.1-8B 从 0 提高到 0.917。信息增益排序在第二个任务族（其原因来自公开 Sigma 规则）上得到重复。采用验证器的证据标准后，控制器单独就能完成两个任务族中的每一个案例，没有任何模型能在此之上带来增益：预先登记的检验比较了由 Qwen2.5-72B 决定何时停止的配置，没有发现增益（$+0.000$ 和 $-0.028$）。在我们评测的四种注入文本下，带守卫的 \hesp{} 在任何模型上都没有把攻击判为良性，而每个自行决定并给出结论的模型都服从了注入的指令；提供这一保护的组件是结束守卫。伪造的观测同样能骗过控制器，而要求良性结论得到不同来源组的佐证，可以把这些案例变为升级，代价落在良性告警上。真实日志解析和开放世界假设仍未经检验。
\end{abstract}
