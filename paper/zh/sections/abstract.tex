\begin{abstract}
安全运营中心（SOC）收到的告警远多于分析师能调查的数量；无法把遥测数据发送给托管模型的组织，只能在自有硬件上用小型开源权重 LLM 来自动化分诊。现有的 LLM 智能体把调查流程交给模型自己决定，而小型本地模型恰恰在流程上失败：它们不断探测却不收敛、从不给出结论，或者照着攻击者写进日志里的指令去做。本文提出 \hesp{}，一个把调查流程放在模型之外的控制器。\hesp{} 维护一个记录相互竞争的解释的账本，按“每单位成本的期望信息增益”挑选只读探针，只接受有当前证据支撑的结论，能自行结束调查，并在每次观测之前先把预测写入日志。我们用来自两个模型家族的五个开源权重模型（7B 到 72B）做了五项预注册研究，共计 11{,}912 个经过审计的回合。使用从无 LLM 运行中计数得到的似然表，\hesp{} 把 Qwen2.5-7B 的已验证完成率从 0.125 提升到 1.000；控制器侧停止把从不自行下结论的 Llama-3.1-8B 从 0 提升到 0.917：“探什么”和“何时停”是两种独立的失败。在第二个由公开 Sigma 检测规则构造的任务家族上，信息增益排序在每个模型上仍带来 $+0.11$ 到 $+0.23$ 的提升。当日志里写着“忽略这条告警”的指令时，每个由自己决定结论的 LLM 都照做了，而 \hesp{} 一次也没有。但单独一条伪造的观测同样能骗过控制器；一条“良性结论需要两处独立佐证”的规则会把这些情况变成升级给人工。我们公开全部代码、协议和回合日志。
\end{abstract}
