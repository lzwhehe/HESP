\section{Conclusion}
\label{sec:conclusion}

Small local models can triage security alerts reliably when an external controller supplies the investigation discipline they lack. The controller tracks competing explanations, chooses probes by information gain per cost, and accepts only evidence-backed verdicts. Pre-registered studies with five models show that this works without oracle prediction tables. The information-gain ranking contributes on every model that concludes. Taking probe choice away from a model helps weak planners and hurts strong ones. Choosing what to probe does not, however, make a model conclude. A controller-side stopping rule rescues a model that never concludes, and for that model it accounts for the entire gain. Public security datasets cannot yet test such policies, because they lack the case that matters: an attack that looks like routine work, and routine work that looks like an attack. Building paired, objectively labeled data of that kind is the next step.
