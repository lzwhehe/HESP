\paragraph{Prevalence} On the release behind the reported scores, \oNamed\% of the \oN{} test questions name their end alert closely enough that plain word overlap ranks it first among all alerts of the incident (95\% CI \oNamedLo--\oNamedHi), and for \oAdj\% the answer is an entity of that alert (\cref{tab:excytin}). The running example is typical: the question describes the alert it was generated from, because a generated question must be unambiguous, and the description is enough to find it. The rate is the same on the latest release, where we ran the frozen rules once on the test split (\exNamed\%, CI \exNamedLo--\exNamedHi), and on its training split (\exTrainNamed\%).

\paragraph{Exact answers without investigation} Taking the first entity of the requested type from the top-ranked alert answers \oGraph\% of the questions exactly (CI \oGraphLo--\oGraphHi). The same rule restricted to the \texttt{SecurityAlert} table, which any agent can query, answers \oTable\% (CI \oTableLo--\oTableHi). Neither rule reads a log table other than the alert table, follows a pivot, or uses an LLM. The rules are crude: they take the first matching entity when an alert has several, and they fail on questions that ask for a value of a type the keyword list does not recognize. They are a floor, not a ceiling, for what lookup achieves.

\paragraph{Comparison with reported scores} \Cref{fig:floor} places the lookups next to the \oModels{} models reported by the benchmark authors. The graph lookup exceeds the mean reward of \oBelowGraph{} of them, including GPT-4o (\exGptFo); the alert-table lookup exceeds \oBelowTable. The comparison favors the models: the reported reward comes from an LLM judge and adds partial credit for intermediate steps, while the lookups get credit only for an exact final answer. Models below the floor are therefore not measured as weak investigators; on this benchmark, their scores do not show that they investigate at all.

\paragraph{Per-incident scores} The incidents differ in how often their questions name the end alert (\cref{app:excytin}). Across the eight incidents, \oHPos{} of the \oModels{} models score higher where more questions are named (median Spearman $\rho = \oHMedian$). With eight incidents, this correlation can come from any property that differs between incidents; \cref{sec:scores} tests it at the level of single questions, where it does not hold.

\subsection{SIABench: The Attack Has an Address}
\label{sec:siabench}

All \siaTP{} true-positive alerts in the SIABench triage set involve 172.16.0.1 and none of the \siaMajority{} false positives does, so the rule ``true positive iff 172.16.0.1 appears'' is correct on \siaRule{} of \siaN{}. The address is the gateway through which the CIC-IDS2017 attack network reaches the victim network~\citep{cicids2017}; it is a property of how the dataset was generated, not of the attacks. The benchmark gives the alert to the model in the scenario text, so the cue is in the prompt. Answering ``false positive'' for every alert already scores \siaMajorityPct\%. The reported accuracies range from \siaMini\% (GPT-4o-mini) to \siaGptFive\% (GPT-5), with DeepSeek-Reasoner at \siaDeepSeek\%~\citep{siabench}. Without per-question logs we cannot tell which models used the address; the point is that 35 alerts with this structure cannot separate a model that analyzes the packet capture from one that does not.

\subsection{GUIDE: The Grade Follows the Organization}
\label{sec:guide}

GUIDE's \gIncidents{} training incidents come from \gOrgs{} organizations, and the organization alone carries \gMIorg{} of the \gH{} bits of entropy in the grade; several large organizations give every incident the same grade. Repeating the grade that the same organization gave the same detector earlier is correct on \gHistPct\% of later incidents (time split within each organization, \gDev{} incidents; \gSeen\% have such history), with true-positive recall \gHistTP. Classifiers that use only the incident's own alert and evidence metadata, trained on other organizations, reach accuracy \gHeldMin--\gHeldMax, below the majority class (\gHeldMajority). The label records an organization's triage policy at least as much as the incident; a model that is evaluated on GUIDE with organization identity or history available can score well by recalling the policy.

\subsection{OTRF: Attacks Are Named, Benign Events Are Routine}
\label{sec:otrf}

In \otRec{} recordings of remote-execution techniques, we found \otN{} distinct service and scheduled-task alerts: \otAttack{} from the emulated attack and \otBenign{} from the operating system. A rule on the alert text alone is correct on \otRuleCorrect{} of \otN. Six of the eight attack alerts are named by their tooling (\texttt{MordorSchtask}, a 20-letter random service name, and similar), and the benign alerts are Windows updates, group-policy tasks, and per-user services, never an administrator using the same tools. The two exceptions are one scenario, a task named \texttt{EventCacheManager} placed in the Windows \texttt{SoftwareProtectionPlatform} task folder. It is separated by a single probe: unlike every system task in the recordings, it was created by a domain user over a network logon (\cref{app:otrf}). Triage tasks built from such recordings test whether a model recognizes attack-tool names.

\subsection{Our Own Environments: A Script Solves Them}
\label{sec:own}

Benchmarks built by hand have the fourth kind of shortcut. In two simulated triage environments we built for earlier work on LLM triage agents, a controller without an LLM, which chooses probes by expected information gain and stops when one observation confirms the leading cause, verifies the correct cause in \envSec{} of \envSecN{} sec-triage cases and \envSigma{} of \envSigmaN{} sigma-triage cases. With the script already perfect, these environments cannot show that a model investigates better than a fixed procedure, and none of the five open-weight LLMs (7B to 72B parameters) that we placed in the loop did better. The environments specify which observation each cause produces; once that model is written down, triage is a lookup in it. We return to the remedy, a paired design, in \cref{sec:design}.

\smallskip\noindent\textbf{Finding 1 (RQ1, RQ2).} Every benchmark we audited admits an investigation-free rule, and each rule reaches or exceeds a large part of the reported model scores: a lookup without an LLM outscores \oBelowGraph{} of \oModels{} agents on ExCyTIn, and an address check is perfect on SIABench.
