\begin{abstract}
Organizations that cannot send security logs to the cloud triage alerts with small, locally run LLM agents. Part of what these agents read is written by the attacker, whose goal is simple: get the alert closed as benign. Today's agents let the model make every decision, so a single sentence planted in a log can close the case. We present \hesp{}, a controller that takes these decisions away from the model. \hesp{} queries the most informative evidence first, tracks how well each candidate cause fits it, and accepts a verdict only when the recorded evidence supports it; the model only proposes next steps and reads raw logs. This leaves the attacker two ways in: forging a data source, and misleading the model while it reads. \hesp{} closes both: a benign verdict must be backed by two independent sources, and never by the model's own reading. We evaluate \hesp{} with five open-weight models (7B to 72B) on three simulated triage settings. No attack we tested closes a case under \hesp{}, whereas without these rules up to all attacks do. Taking the decisions from the model costs no accuracy: in two of the three settings, the controller alone resolves every case.
\end{abstract}
