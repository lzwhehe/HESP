\paragraph{Disclosed pre-freeze runs.} Before freezing v0.6, v0.8, and v0.9, we ran pipeline smoke tests of 10 to 16 episodes. For v0.9 we also ran an LLM-free simulation on disjoint development seeds. None of these runs enters any analysis. The simulation informed the stated expectation for P1 but was not used to choose the threshold, which was carried over from v0.4.

\section{Errata}
\label{app:errata}

\begin{description}
  \item[E-1] v0.5 reported that all three primary intervals excluded zero; the 72B interval is $[0.000, 0.236]$.
  \item[E-2] The v0.5 per-episode journals were not archived before the rented GPU was released. Summaries can be recomputed, but the raw events cannot be re-audited by third parties. From v0.6 on, journals are archived and hashed before compute is released.
  \item[E-3] The v0.5 manifests carried stale metadata from v0.4.
  \item[E-4] In v0.5 the random-selection control could see the EIG ranking. Fixed by the blind arms of v0.8.
  \item[E-5] Before v0.6, prediction tables were derived from the environment's generator (near-oracle). Addressed by the empirical tables of v0.6.
  \item[E-6] The ground truth of the descriptive security metrics mishandled drifting episodes and was corrected twice. Every summary script now checks that each verified verdict equals the ground truth used.
  \item[E-7] In v0.6 the Memory-only ledger used designer tables while \hesp{} used empirical ones. The asymmetry favours the baseline, so v0.6's primary endpoint is, if anything, underestimated. Fixed in v0.8.
\end{description}
